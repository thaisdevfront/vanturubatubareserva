# vanturubatubareserva
Este site é uma plataforma institucional e de conversão de alta performance (Landing Page) desenvolvida sob medida para a agência Van Tur Ubatuba Reserva.

O projeto combina uma estética visual sofisticada com ferramentas práticas para otimizar a experiência do usuário e as vendas. Suas principais características são:

## Características do Site
Design Premium e Responsivo: Inspirado no mercado náutico internacional, utiliza uma paleta em tons de azul-marinho profundo, branco puro e detalhes dourados. A interface é totalmente adaptável para celulares, tablets e computadores.

Animações de Introdução Fluidas: Integra um sistema de carregamento inteligente através de IntersectionObserver, fazendo com que as sessões e imagens surjam suavemente na tela à medida que o usuário navega, gerando maior retenção visual.

Grid de Roteiros Interativo: Apresenta de forma organizada os quatro principais destinos e ilhas de Ubatuba, com efeitos visuais ao passar o mouse (hover) que revelam mais detalhes sobre cada passeio.

Calculadora e Formulário de Cotação Inteligente: Permite ao cliente inserir dados essenciais (Nome, WhatsApp, Tipo de Embarcação, Data e Número de Passageiros) e ver o valor final calculado em tempo real, com base na tarifa fixa de R$ 150,00 por pessoa.

Integração Direta com WhatsApp: Ao clicar no botão de confirmação, o site compila todas as informações preenchidas em um relatório perfeitamente estruturado e o envia diretamente para o chat da agência, transformando o visitante em um lead pronto para o fechamento.
